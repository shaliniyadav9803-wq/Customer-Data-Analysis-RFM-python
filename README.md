# Customer Data Analysis & RFM Segmentation

## 📌 Project Overview

This project analyzes customer and transaction data to understand purchasing behavior and identify meaningful customer segments.

The analysis uses **RFM (Recency, Frequency, Monetary) analysis** to evaluate customers based on how recently, how frequently, and how much they purchase.

## 🎯 Project Objectives

- Analyze customer and transaction data
- Calculate Recency, Frequency, and Monetary values
- Assign RFM scores to customers
- Create customer segments based on RFM scores
- Analyze the distribution of different customer segments
- Identify customer groups based on purchasing behavior
- Perform Pareto analysis to examine customer revenue contribution

## 📊 RFM Analysis

RFM analysis is based on three customer-level metrics:

| Metric | Description |
|---|---|
| **Recency** | Number of days since the customer's most recent purchase |
| **Frequency** | Number of transactions made by the customer |
| **Monetary** | Total amount spent by the customer |

RFM scores are calculated using a **1–5 scoring system** and combined to create customer segments.
